## VM 中待执行的验收

1. 外部代理占用普通/TUN端口：Ares 报冲突，外部进程和系统代理完全不变。
2. 普通和 sudo/TUN 启停、拒绝退出、API 超时：无重复核心，失败状态准确；核验 sudo 父进程退出与核心子进程退出一致，若平台行为不符须使用专用监督机制，不能恢复按端口清理。
3. 系统代理原来开启/关闭、空 bypass、设置写到一半失败、授权取消、服务插拔：检查读回值和快照保留；禁用端点残留地址不代表活动代理，恢复验证比较实际启用端点和 bypass。
4. TUN 双向切换，在配置验证、停止、启动、API 验证、系统代理迁移各阶段注入失败，确认旧运行态恢复或明确报恢复不确定。
5. MITM 双向切换及 TUN+MITM 组合：路由迁移失败时监听器保留；检查旧连接断开重连和新连接上游端口。
6. 真实 YAML、provider 配置、带额度头的 Base64、认证失败页、非法 YAML、连续刷新/删除/编辑；确认 mihomo 候选验证兼容 provider 和资源依赖。
