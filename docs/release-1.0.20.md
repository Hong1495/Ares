# Ares 1.0.20

- **Scenes:** choose which settings a scene saves, and review what will change before switching. Unselected settings stay as they are. The review shows application route changes and warns when a switch removes local policy definitions. Undo is available while the saved settings still match the last switch.
- **Resources:** import node links without losing input on an error. Review additions, edits, and removals before applying, then add a saved node or provider to an existing policy group.
- **Node Providers:** see members, update times, and the running core’s last health measurements in Resources. The shortcut in Proxies goes to the same page.

Requires macOS 14 or later on Apple Silicon. Includes mihomo v1.19.34. Update archives use Sparkle Ed25519 signatures; the app is ad-hoc signed and is not Apple-notarized.
