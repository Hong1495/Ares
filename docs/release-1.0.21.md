# Ares 1.0.21

- Workspace controls: search, filters, and common actions use a consistent layout. Open application routing from a selected Activity row, compose policy groups directly, and add a subscription or import a file without opening a menu.
- Dashboard: see resource composition, device access and live connections, application rule targets, policy group distribution, and saved scenes at a glance. Unavailable live counts are shown as a dash.
- Analysis and Logs: inspect a selected request directly, reset request filters together, and follow or export matching logs from the toolbar.
- Menu bar: the first shortcut opens Dashboard and uses the same gauge icon as the sidebar.

Requires macOS 14 or later on Apple Silicon. Includes mihomo v1.19.34. Update archives use Sparkle Ed25519 signatures; the app is ad-hoc signed and is not Apple-notarized.
